# Examples 测试工程说明

本目录包含三个用于测试不同类型系统异常和死机错误的示例工程。

## 工程列表

### 1. Array - 数组与内存访问异常测试

该工程用于测试以下类型的硬件异常：

- **数组越界访问 (Array Out-of-Bounds)**
  - 故意访问数组边界之外的元素
  - 触发内存访问异常
  
- **非法代码地址跳转 (Illegal Code Address)**
  - 跳转到无效的内存地址（如 0x00000000）
  - 触发 HardFault 异常
  
- **未定义指令 (Undefined Instruction)**
  - 执行未定义的指令 (UDF)
  - 触发指令执行异常

### 2. Stack - 栈溢出测试

该工程用于测试栈溢出相关的异常：

- **栈溢出 (Stack Overflow)**
  - 测试深度递归或大量局部变量导致的栈溢出
  - 验证 FreeRTOS 任务栈保护机制

### 3. Verrouillage - 死锁测试

该工程用于测试多任务同步问题：

- **死锁 (Deadlock)**
  - 测试多任务之间的资源竞争
  - 验证互斥锁使用不当导致的死锁情况
  - 测试任务间同步机制的正确性
